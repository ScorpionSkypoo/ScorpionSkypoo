# 嗨，我是小蠍 (Scorpio) 🇹🇼

在台灣寫寫程式、發發呆，討厭沒有因果關係的黑盒與廢話。  
目前專注在 Android 系統工具、注音輸入法與後端架構。

---

### 📌 關於我 (About Me)
- 📍 **所在地**：台灣 (Taiwan 🇹🇼)
- 💻 **專注領域**：Android (AOSP / IME)、TypeScript / JavaScript、Kotlin、分散式架構
- 🎧 **日常偏好**：J-POP / Anime OST（Aimer、澤野弘之、YOASOBI）、咖啡、吹冷氣發呆
- ☕ **開發風格**：實事求是，代碼邏輯必須清楚可追溯

---

### 🛠️ 公開開源專案 (Open Source Projects)
- [**ScorpionBopomofo**](https://github.com/ScorpionSkypoo/ScorpionBopomofo)  
  Android 智慧注音輸入法：整句選字、免聲調連續輸入、拼音容錯推論，詞庫支援模組化自訂與匯入匯出。
- [**scorpio-ime-data**](https://github.com/ScorpionSkypoo/scorpio-ime-data)  
  Scorpio 智慧注音線上詞庫：台灣在地地名、流行用語、網路黑話、顏文字與新詞雷達語料。

- **Languages**: TypeScript, JavaScript, Kotlin, Node.js
